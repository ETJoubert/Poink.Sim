# BootstrapIcon.cs

Inline SVG path data for the small subset of Bootstrap Icons (https://icons.getbootstrap.com, MIT License) used across the app. Kept as raw path markup (no outer &lt;svg&gt;) so the Icon component can render it with a single shared wrapper that inherits the surrounding text color via fill="currentColor".
