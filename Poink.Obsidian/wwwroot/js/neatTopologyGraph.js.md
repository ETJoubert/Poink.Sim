# neatTopologyGraph.js

Canvas renderer for one NEAT genome's topology. The Blazor component (NeatTopologyGraph.razor.cs) owns all layout/color logic and hands over a per-draw payload of pre-computed node/edge positions (0-100% coordinates) and color tokens; this module only paints pixels. Same split as xGrid.js.
