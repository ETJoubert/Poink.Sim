# marketChartSparkline.js

Standalone sparkline of a bar list's close prices, with an optional highlighted Lookback Window the user can drag -- unlike marketChart.js's own minimap, this has no lightweight-charts dependency and isn't tied to any chart instance; it just draws whatever ProfilerPage last pushed via setBars/setWindow.
